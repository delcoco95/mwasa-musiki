Administration du site

Réservé aux responsables de l'association. Connectez-vous pour modifier et publier le site.

Comment obtenir ma clé d'accès ?
  1. Connectez-vous sur github.com avec un compte qui a accès au dépôt du site.
  2. Ouvrez Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Nom : « Site Mwasa Musiki ». Durée : 1 an.
  4. Repository access : « Only select repositories » puis choisissez mwasa-musiki.
  5. Permissions → Repository permissions → Contents : « Read and write ». Rien d'autre.
  6. Cliquez sur « Generate token », copiez la clé et collez-la ici. Ne la donnez à personne.
