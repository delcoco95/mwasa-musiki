# Mwasa Musiki

Site vitrine de l'association **Mwasa Musiki** (Nice) : chant gospel, chant individuel, souffle et voix, ateliers d'instruments.

Site en ligne : **https://mwasamusiki.com**

## Le projet

Le site a été réalisé sur mesure pour l'association :

- un site responsive (ordinateur, tablette, téléphone) aux couleurs et avec le logo de l'association ;
- un espace d'administration privé pour modifier le contenu sans connaissances techniques (textes, photos, vidéos, agenda, actualités, mise en page, apparence) ;
- une page de mentions légales et une gestion du consentement conforme au RGPD.

## Technique

HTML, CSS et JavaScript sans framework, avec une petite API PHP pour l'espace d'administration. Le site est hébergé chez OVHcloud.

La documentation d'utilisation et d'exploitation est remise directement à l'association. Elle n'est pas publiée ici.
