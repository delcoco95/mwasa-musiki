# Mwasa Musiki

Site vitrine de l'association **Mwasa Musiki** (Nice) : ateliers de chant gospel collectif et individuel, souffle et voix, initiation aux instruments de musique.

## Contenu

- `index.html` : la page du site (HTML et CSS, sans dépendance à installer)
- `img/` : logo officiel et photos

## Mise en ligne

Le site est publié avec GitHub Pages depuis la branche `main` (dossier racine).
Pour modifier un texte, éditez `index.html` puis faites un commit : le site se met à jour en une à deux minutes.
